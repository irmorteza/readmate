# WortTap Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A PWA that OCRs a photo of a German book/newspaper page via Amazon Textract and shows a tappable box over every word, with hyphenated words merged across line breaks.

**Architecture:** A Python Lambda (Function URL) wraps a pure `process_image(bytes, engine)` function: engine adapter → `normalize` → `filter_noise` → `merge_hyphenated`, returning an `OcrResult` in normalized 0–1 coordinates. A Vite + TypeScript PWA resizes the photo, posts the same blob it displays, and renders percent-positioned boxes. `contract/ocr-result.schema.json` plus golden `contract/example.json` keep both languages in sync.

**Tech Stack:** Python 3.13, boto3, pytest, jsonschema, ruff, AWS SAM; Vite, TypeScript, vite-plugin-pwa, Vitest.

**Spec:** `docs/superpowers/specs/2026-10-17-wort-tap-design.md` (section numbers below, "§n", refer to it)

## Global Constraints

- Lambda runtime python3.13 or newer, arm64, 512 MB, timeout 15 s, `Handler: worttap.handler.handler`, `CodeUri: ../backend/src`; `boto3` pinned explicitly in `backend/requirements.txt`.
- Region `eu-central-1` (fallback `eu-west-3` if Textract unavailable).
- Wire JSON keys are camelCase (`boxIds`, `lineId`, `lineIds`, `wordId`); `TypedDict`s in `pipeline/types.py` use the wire names; coordinates are 0–1 relative to the image.
- Auth header `X-Pilot-Token`, compared with `hmac.compare_digest`; never log image bytes or the token.
- Decoded body limit 5 MB; client resizes to long edge ≤ 2000 px, JPEG q 0.85, retry q 0.7 if > 4 MB; API fetch timeout 20 s.
- Error table (HTTP / code): 400 `BAD_REQUEST`, 401 `UNAUTHORIZED`, 413 `TOO_LARGE`, 422 `UNREADABLE_IMAGE`, 429 `BUSY`, 502 `OCR_FAILED`, 500 `INTERNAL`; body `{"error": {"code", "message"}}`.
- All UI text is English. Token stored in `localStorage` key `worttap.token`.
- Pipeline functions return new structures and never mutate input.
- Service worker precaches the app shell only; API URL is `NetworkOnly`.
- Phase 2 hook: `onWordSelected({ word, boxes, lineTexts })`.

## Review Focus

1. Textract returns no `LINE` blocks (blank page): backend returns a valid empty `OcrResult` (no `statistics.median([])` crash); the UI shows "No text found — try more light and hold the phone parallel to the page." (Tasks 3, 5, 11)
2. Function URL events carry lower-cased header names, and `Content-Type` may arrive as `image/jpeg; charset=...` or be missing; a missing/`null` body must give 400, not 500. (Task 7)
3. Hyphen-merge edge cases: next line's first box is not a letter (e.g. a noise glyph `|`) → no merge; a box already consumed by a merge is never merged twice (one-box line `ab-` following a hyphenated line). (Task 4)
4. A pasted token with trailing whitespace/newline would make `fetch` fail or the server reject it: the token is trimmed before saving. (Task 12)
5. The browser cannot decode the chosen file (e.g. HEIC on a non-Safari browser, corrupt file): shows "Couldn't read this image. Try another photo." with "New photo", not a hung spinner. (Task 9)
